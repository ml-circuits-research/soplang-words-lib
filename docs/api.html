API: every public name, with what it takes and returns

import { World, parse, ... } from 'sopworld' (or from the single file docs/sopworld.mjs). This page lists everything the library exports and every public method of a world. Names that start with _ are internal and may change. The language is in language.md, the wire types in reference.md, the behaviour in semantics.md.

Conventions used on this page

  • input is SOP Lang text or an array of parsed wires.
  • A change result is { ok, added, derived, filled, merged, removed, violations }: ids of the facts added, ids of the wires rules derived, values put on existing wires ({ id, key, value, via }), facts merged into others ({ id, into }), ids removed, and the violations (empty when ok). It may also have revised (assumptions that gave way) and issues (soft violations recorded).
  • Errors. Methods do not throw for anything a matrix or a fact can cause: they return ok: false with violations. They throw SopError for text that does not parse, and Error for a call that is wrong in itself (an unknown tier, a host function that would replace a built-in). load is the exception: it throws on refusal.
  • Budget. Every method that computes takes { budget: { steps, ms } } (default 5,000,000 steps, no time limit; the world option budget changes the default). When it runs out, a change is refused with a budget violation and the world is unchanged; a reader returns what its entry says. world.stats() reports the last call.
  • Cost is given in: n facts, r rules, m matches of the bodies concerned, h statements in the log.

The examples on this page use this world:

Making a world

new World(options?)

Options, all optional: facts (below), fns, actions, producers, filters (host functions by name; see register), override (let fns replace built-ins: true or names), library (module name to matrix text, for core.use), maxDepth (12), maxSteps (rule firings per change), budget, decimals, strict (refuse a change that leaves no completion), lookahead (true), solver, searchBudget, rank (reorder suggestions and explanations), vocabulary (names of the question, answer and request wires and their keys).

Properties: wires (Map of facts by id), matrix (Map of matrix wires by id), log (the statements), warnings, stamp (a number that changes with every committed change), actions, producers, options.

Throws if fns would replace a built-in without override. Cost: constant.

Facts the host keeps. facts: { city: (where, world) => [...] } gives the facts of a type from the host's own data (a large static table). A pattern of that type asks the provider with the values it fixes (where, keys to values, strings as their text) and matches what comes back like wires: { id, ...keys } or { id, attrs }, values as values or arrays. They are read in rules, denies, aggregates, queries and ask, are told for tiers, and are never stored, forked, logged or snapshotted. A provider must be pure and stable (the same answer for the same where for the life of the world: what a rule concluded from it is never re-examined), may return more than asked (every pattern value is checked), and should be bounded: each fact it returns costs one step of the budget, so a pattern that fixes nothing pages through the whole table under the budget. A rule needs a wire of the world to fire: a provider's facts alone start nothing. Returned facts are kept by id while the world lives. Cost: a city table of 1,000 rows takes 0.2 ms to build, against 28 ms as wires, and the snapshot is 1 kB instead of 113 kB (node bench/facts.mjs).

World.fromJSON(snapshot, options?)

Rebuilds a world from what toJSON() returned, by replaying its log. Host functions are not in a snapshot: pass the same options. Returns the world. Cost: that of telling the log again, O(h) changes.

World.audit(wires, matrix?, options?)

Checks wires that came from somewhere else against a matrix, without refusing at the first problem. Returns { ok, violations, issues, world }; world holds the wires that could be loaded. Cost: one validation of everything.

World.diff(a, b)

The same as a.diff(b).

Changing a world

world.tell(input, options?)

States wires: facts, matrix wires, or both. Options: dry (evaluate and undo), strict, tier (default told), budget. Returns a change result. Cost: O(matches the new wires take part in) for the chase, plus validation of the touched wires; telling matrix wires recompiles the matrix and validates everything, O(n·r).

world.load(input)

tell that throws an Error when the change is refused. For matrices and fixtures, where a refusal is a mistake in the program.

world.use(name)

Loads the module name from the library; the same as telling a core.use wire. Returns a change result.

world.fill(id, key, value, options?)

Gives a value to a key of an existing fact. Options as for tell. A different value for a single-valued key that already has one is a conflict (use revise), except for a fluent, where it is a new statement of the state. Returns a change result.

world.revise(id, key, value, options?) and world.revise(id, values, options?)

Replaces told values, with everything that followed from them, in one transaction. Returns a change result with revised: the cells that were replaced or recomputed.

world.retract(id, options?)

Removes a told fact, the facts that refer to it, and what was derived from them alone. Refused (unknown-wire) for a wire that was not told, and when the world that remains is not valid. Returns a change result with removed. Cost: O(what depended on the wire).

world.replace(id, input, options?)

Retracts the fact id and tells input in one transaction; references to the fact stay valid when the new wire has the same id or identity. Returns a change result.

world.applyPatch(patch, options?)

Applies several changes that must hold together, all or nothing. A patch is an array of { id, key, value } fills, or { wires, fills, sets, retract, replace }: wires to tell, values to add, values to replace, ids to retract, and wires to replace in place. replace: { id, attrs } (or a list of them) gives a told wire exactly the keys in attrs (keys it had and attrs lacks are dropped) and keeps its id, so the wires that refer to it stay; what was derived from the old content is withdrawn. Options: strict, tier, budget. Returns a change result, with replaced (ids) when there were replacements. undo takes a patch back as one statement.

world.sync(collection, input, options?)

Makes a collection of told wires equal to a list, in one transaction. collection is a type (its told facts and those of its subtypes) or { prefix } (the told facts whose id starts with it); input is SOP text or parsed wires. A wire with a new id is told; one whose content differs from what was told is replaced in place (its id, and the wires that refer to it, stay); one that is the same is left alone; a wire of the collection that is not in the list is retracted. Returns the change result with told, replaced, retracted and same (ids). All or nothing. undo takes back what it told and replaced; like any retraction, what it retracted is not undone (use a mark). Options: strict, tier, budget. Cost: one pass over the told wires, then the patch.

world.apply(assignment, options?)

Fills the values of an assignment ([{ id, key, value }], as solve returns) in one transaction. Option via names where they came from. Returns a change result.

world.undo(n = 1, options?)

Takes back the last n statements. Returns { ok, undone, removed, added, changed, violations }; nothing-to-undo when the log is empty. Statements that only touched wires of transient types are passed over and kept. Retractions are not taken back (use a mark). Cost: O(h) changes, since the world is rebuilt from the statements that remain.

world.redo(n = 1, options?)

Tells again what the last undo took back (or the last n undos), as the statements they were. Returns { ok, redone, removed, added, changed, violations }; nothing-to-redo when nothing was undone since the last statement that is not transient. If a statement cannot be told again, nothing is, and the world stays as it was. Cost: that of telling the statements again.

world.mark() and world.rewind(mark)

mark() returns a point to come back to (a fork: the world's next change copies only what it touches). rewind(mark) makes the world exactly what it was, and returns { ok, removed, added, changed }. A mark can be used again.

world.act(request, options?)

Runs an action. request is { action, args }, a core.request wire, or its text. Returns { ok, status, value, result, missing, violations } with status done, missing (arguments to ask for), refused, error (the host function threw), unsupported (no such action) or budget.

A host function gets (ctx, args). ctx.tell(input, { now }) queues a statement and returns { ok: true, queued: true }; the queue is propagated and validated together at the first read (ctx.find, ctx.val, ctx.vals, ctx.get, ctx.query, ctx.ask, any use of ctx.world), before ctx.fill, ctx.replace, ctx.retract, and at the end (S57). ctx.flush() does it now and returns the change result; { now: true } checks one tell as it is told. A refusal's violations carry queued: [{ index, ids }], the queued tells involved. Cost: one propagation for the queued tells, against one per tell (node bench/act.mjs).

Completing a world

world.open(id?)

The open keys (required, no value) of the world or of one wire: [{ id, type, key, ask }]. Cost: O(n), or O(keys of the wire).

world.suggest(id, key, options?)

The values that could go in a key, most plausible first: [{ value, source, count }], source being default, enum, range or wire (a wire of the slot's type). Only values the world accepts are returned; with lookahead, only values that some complete assignment contains. On budget: the array found so far, with a budget property. Cost: one trial per candidate, or one search per candidate with lookahead.

world.next(options?)

What can be done about the open keys without changing anything: { fills, questions, dead }. fills are values that are forced or defaults (kind), questions the keys that need an answer (as question wires with the options), dead the keys with no possible value. With { review: true } also review: the assumptions a host may want confirmed, weakest first; it is a pass over every value, so it is computed only when asked for. Cost: one trial per candidate of each empty slot; nothing at all when the matrix has no required slot and no default.

world.canComplete(id?)

Cheap: whether some empty slot of the world (or of one wire) has a candidate that completion could try: an optional key with a default, or a required key with a default, an enum, a range, or a type that has wires. It does not try the values, so true does not promise that complete() fills anything. For a host that completes after every change and wants to skip the call when there is nothing to look at. Cost: one pass over the wires whose type has such a slot; constant when the matrix has none.

world.complete(options?)

Applies what next found: forced values, with { defaults: true } the defaults, with { choose: true } one full solution of what is left (tier guessed). Returns { filled, questions, dead, pending }. A call on a world that has not changed since a call with the same options that filled nothing returns that answer again at once.

world.step(input, options?)

One turn of a dialogue: tell(input), then complete(options). Returns the change result with questions, dead and pending added.

world.answer(question, value)

Fills the key a question wire (from next, complete or step) is about. Returns a change result.

world.solve(options?), world.solveReport(options?), world.satisfiable(options?)

Search for values of all open keys that the world accepts together. Nothing changes. Options: solver, budget (the solver's own), limit (the step budget of the call). solveReport returns { status, assignment, reason, stats, solver } with status sat, unsat or unknown (S46); solve returns the assignment or null; satisfiable is false only for unsat. Cost: exponential in the number of open keys in the worst case; the default solver learns from conflicts.

world.solveAsync(options?)

solveReport for a solver that runs outside (solvers.external, dimacs, clingo with an asynchronous exec). Returns a promise of the report.

world.abduce(goal, options?)

What would have to be assumed for goal (wires, as text with ids) to hold: [{ assume, fills, text, cost }], cheapest first; empty when nothing is needed or nothing works. Options: max (10), maxDepth (3 rule steps), maxAssumptions (4). On budget: what was found, with a budget property. adopt(world, explanation) applies one.

Asking

world.ask(query, options?)

Matches patterns (text; ids may be left out) against the facts and returns the bindings, one object per match: [{ variable: value }]. A pattern's own id binds to the matched wire's id. Option at: as of that place in the sequence. On budget: the matches so far, with a budget property. Cost: O(m), using the indexes for fixed values.

world.holds(query, options?)

True when ask would return at least one match.

world.query(question, options?)

Asks for a value, with a status. question is { type, where, seek, mode } or { about, seek }, a core.question wire, or its text. Modes: value (default), list, count, exists, check (is where[seek], or value, the value the world has? yes, or no with actual), abduce. Options: record (tell the question and the answer as wires), suppose (default true: S53), at. Returns { status, value | values, from, via, tier, rests, wires } and, by status, alternatives, missing, reason, issues, howto, supposed, violations. The statuses are defined in semantics.

world.get(id), world.has(id), world.resolve(id), world.ofType(type)

get returns the fact { id, type, attrs, meta } or undefined; attrs maps each key to an array of values. has says whether it exists. resolve returns the id of the wire that an id names now (after a merge), or the id itself. ofType returns the facts of a type and of its subtypes. Do not modify what they return. Cost: constant; ofType O(result).

world.schema(type)

What the matrix says about a type: { type, extends, lineage, closed, keys }, each key with its slot's attributes and inherited; null for a type the matrix does not mention.

world.explain(id)

Where a wire comes from: { id, wire, tier, told, via, from, fills }: the wire as text, whether it was told, else the rule (via) that derived it, the wires it was derived from (each explained in turn), and the values that were added to it later (fills, each with key, value, via, from); null for an unknown id.

world.tier(id, key?) and world.assumptions()

tier is the certainty of a cell, or of a wire as a whole: told, derived, forced, default, guessed or a declared tier; undefined when there is no such cell. assumptions() lists every cell weaker than derived, weakest first: [{ id, key, value, tier, dependants }].

world.told()

The facts as they were stated, without what rules, defaults and searches added: an array of wires that can be told to another world.

world.describe(options?) and world.diff(other)

describe returns a summary as plain data: { types, wires, open, assumed, issues, changes }. Options: about (one wire and what is within depth references of it), since (changes after that sequence number), last (20 changes). diff returns what is different in another world: { same, added, removed, changed }. Cost: O(n).

world.check(patch?, options?)

With a patch: what applyPatch(patch) would return, without changing anything. Without one: validates the whole world and returns { ok, violations, issues }.

With { query } or { ask } (a question for query, patterns for ask) the patch is applied in a transaction that is then undone, and the result also has answer (what query gives on the world with the patch) or rows (what ask gives there). The same from the other side: query(q, { given: patch }) and ask(patterns, { given: patch }) answer on the world as it would be with the patch; a patch the world refuses gives the status refused with the violations. Nothing changes.

Worlds, time and history

world.fork()

An independent world with the same content. Nothing is copied: each of the two worlds, at its first change, puts a copy-on-write layer over what they share and writes there, so a change after a fork copies only the wires and index entries it touches. Cost: constant; the first change after it costs about what the same change costs without a fork, whatever the size of the world (node bench/fork.mjs).

world.trial(fn, options?)

Runs fn(world) and undoes whatever it changed; returns what fn returned, or undefined on budget. For what-if questions without a fork.

world.asOf(at, fn, options?), world.seqOf(id), world.compare(idA, idB)

seqOf is the place of a wire in the sequence. compare is negative when the first wire comes before the second, positive when after. asOf runs fn against the world as it was at place at and returns its result; the world is unchanged. Cost of asOf: O(wires after at).

world.history() and world.on(listener)

history() returns the committed events, oldest first: [{ seq, op, ... }]. on(listener) calls listener(events, world) after every committed change and returns a function that stops it.

world.toSOP(options?) and world.toJSON()

toSOP writes the facts as text, in order of arrival. Options: schema (the matrix too), derived (true; false leaves out derived wires), provenance (add core.via and core.from). toJSON returns { format: 'sopworld', version, log }, for World.fromJSON.

world.register(kind, name, fn, options?)

Adds a host function after the world was made. kind is function ((args, world) => value, for calcs, checks and effects), action ((context, args) => value), producer ((context) => value) or filter ((value, { world, name }) => text, for ?v:name in a reason). A function with the name of a built-in throws unless { override: true }. Returns the world.

world.cannot(reason)

For host functions: say why there is no result, before returning nothing. A query that supposed a wire and needed the result answers unsupported with that reason.

world.stats()

The cost of the last call: { steps, limit, exhausted, site, sites, ms }, sites giving the steps per place (match, chase, negation, aggregate, fluent, withdraw, validate, complete, ground, solve, abduce, induce).

Functions

parse(text, options?), tokenize(text, options?)

parse returns the wires of a text: [{ id, type, attrs, pattern }], attrs mapping each key to the array of its value tokens. Options: anonymous (a declaration may leave out its @id, for queries), lenient (read what versions before 0.6.1 read: an id twice in one text, escapes JSON does not have, a quote or backslash in an atom). It throws SopError listing every error of the text (the list). tokenize returns the tokens: [{ t, line, column, offset }]. Cost: linear in the text.

format(wire, options?) and serialize(wires, options?)

format writes one wire: on one line; with { multiline: true } one entry per line; with { canonical: true } in the canonical form (entries sorted by key, strings in one spelling). serialize writes several wires, each followed by a line end, with the same options; serialize(wires, { canonical: true }) gives the same bytes for the same wires.

str(value), quote(text), readValue(token), writeValue(value)

str gives the text of a string token (escapes decoded) and returns any other value unchanged; quote gives the string token of a text, in the canonical spelling (the escapes of JSON). readValue gives a token as data, { kind, v } with kind atom, string, ref or var; writeValue is its inverse (and throws for another kind). They are what a host with its own parser needs to hand over wires.

SopError

What parse, tell and the other methods throw for text that is not SOP Lang. It has message, line, column and offset of the first error, and errors: every error of the text as { message, offset, line, column }.

unify(a, b, bindings?) and walk(term, bindings)

unify matches two values (an atom, a ?variable, a $reference, also $?variable) and returns the bindings, extended from those given, or null when they cannot be the same. walk returns what a value stands for under bindings.

abduce(world, goal, options?) and adopt(world, explanation)

abduce is world.abduce. adopt tells an explanation's wires and fills (tier guessed) and returns { ok, results }.

induce(examples, options?), induceRule(examples, options?), induceSlots(wires, options?)

induce generalises examples ([{ when, then }], text or wires) into one rule, or with { kind: 'deny' } into a deny: { text, calcs, tests, skipped, coversNegative, variables, examples }. Options: name, why, tolerant (skip examples of another shape), negatives, budget. induceRule returns only the text. induceSlots proposes slots for observed wires. What they return is text to review and tell.

quantity(value)

Reads a number with an optional unit: { n, unit }, or null.

solvers, Problem, Sat, toDimacs(data), toASP(data)

solvers.cdcl() (the default) and solvers.backtrack() are built in. solvers.external({ run }), solvers.dimacs({ exec }) and solvers.clingo({ exec }) hand the problem to a program outside; what it proposes is verified by the world. new Problem(world) is the search problem of a world (variables, nogoods, verify, toJSON); toDimacs and toASP write it for a SAT or an ASP solver. Sat is the built-in SAT solver (addClause, solve, model).

builtins, aggregates, GRAMMAR, MODIFIERS, SCHEMA_TYPES

Tables, for tools: the built-in functions and aggregates by name; for each matrix wire type the attributes it reads (GRAMMAR; a name that ends in . is a prefix); the attributes that may stand on any pattern or template (MODIFIERS); the types that make a wire a matrix wire (SCHEMA_TYPES).

version and build

version is the version of the library. build is { version, hash, date }: which build a single file is (hash and date are null when running from the sources); docs/version.md says the same.
