sopworld

A small engine that keeps a set of SOP Lang wires consistent with rules written as wires. It derives what follows, completes what is missing, asks for what it cannot decide, and refuses what is not allowed.

What it is

A world holds facts. A consistency matrix says which worlds are possible: which keys a wire has, what must exist when something else exists, what may never happen. The matrix is written in the same language as the facts, as pattern circuits with variables.

Every change goes through one transaction. Either the world accepts it together with all its consequences, or nothing changes and you get the reason.

One file, two places to run

The library is built into a single file with no dependencies. The same file runs in Node and in a browser, so a world can live on a server, in a page, or in both with the same matrix.
