# The host contract

What an application (the host) supplies, and what it must not rebuild because the library
does it. A host that keeps to this writes reading and rendering only. The jobs themselves
are in [capabilities](capabilities.md); a worked start is the [quickstart](quickstart.md).

## What the host supplies

| The host supplies | How it reaches the library | Why it is the host's |
| --- | --- | --- |
| **Reading**: text into requests (`{ action, args }`), one or more candidate readings per message, best first | `turn(world, readings)`, `world.act`, `world.score` | language, spelling, models: the library knows no language |
| **The lemma of a word** | `createCatalog({ lemma })`, `world.register('lemma', fn)` | word forms are language |
| **Rendering**: drawing, layout on screen, the wording of replies in its language | reads `result.diff`, `why`, `schemaCard`; replaces `actReply` with its own (`turn(w, r, { reply })`) | a user interface |
| **Translation** at the boundary | before reading, after replying | a language |
| **Fetching and storage**: reading a catalog path (file, `fetch`), keeping a session | `createCatalog({ read, cache })`, `world.toJSON()` / `World.fromJSON` | the network and the disk |
| **Its own signals** (an encoder's score per world) | `route(world, request, { scores })` | a model |
| **Host actions** (what the host carries out itself) | `core.action fn=` with `new World({ actions })`, or a type named like the action | the host's side effects |
| **Cause signals and replays** for the failure ledger | `ledgerGroups(rows, { signals })`, the rows it appends | its own evaluation |
| **A guard** around a whole turn (time, memory) | the library's budgets bound each call (`{ budget }`) | the host owns the process |

## What the host must not rebuild

| Job | In the library |
| --- | --- |
| Declaring a world that does things, checking it | `std.schema`, slots, `tools/validate.mjs` |
| The acts (make, remove, change, place, connect, group, pick, ask, copy, send, save, load, undo, redo, show, teach, forget, complete), their diff, undo, why | `std.acts`, `world.act`, `world.why` |
| One sentence all or nothing | `world.act([...])` |
| Dry runs, refusals with alternatives, the graded fallback | `world.score`, `turn` |
| Choosing a world | `route` |
| Filling what a request leaves out, by tiers, with the source | `std.fill`, `std.know`, `std.focus` |
| The focus of a dialogue | `std.focus` |
| Relations kept between things, rows, sets | `std.relations`, `std.boxes` |
| One thing seen in several views; taught facts | `std.schema` aspects and views, `show`, `teach` |
| Loading knowledge by lookup, caching, offline bundles | `createCatalog`, `bundleReader`, `tools/build-bundle.mjs` |
| Cards, example sentences, replies, the coverage grid, test files | `schemaCard`, `schemaExamples`, `actReply`, `schemaGrid`, `gridTests` |
| The failure ledger's format, append and grouping | `ledgerAppend`, `ledgerGroups`, `stageOf`, `tools/ledger.mjs` |
| Finding reuse between worlds | `tools/reuse.mjs`, the option `advise` |

## Where this agrees with PSys2's host boundary, and where not

PSys2 wrote `docs/host-boundary.md` from its side (at its main 9e370c47). The split is
the same: reading, translation, the user interface, its server, its own worlds' content
and its evaluation stay in the host; mechanisms go to the library, facts to
sop-knowledge-worlds. Where the two differ, this wording is the interface:

- **Names.** It names `std.things`, `std.dialogue`, `std.space`, `std.knowledge`,
  `std.route`. Here: shared things and views are part of `std.schema` / `std.acts`
  (`show`); the dialogue is `std.focus` with `turn`; space is `std.relations` with
  `std.boxes`; knowledge loading is `createCatalog` (a function, not a module of rules);
  routing is `route`.
- **An English pack of the acts.** It plans the acts' English forms as "its English pack".
  The library ships no word lists: words for acts come from knowledge (`k.actions`) or the
  host. `actReply` writes plain English as a default only.
- **The compute budget.** It lists its per-turn tick budget as general. The library bounds
  each of its own calls (`{ budget }`, `world.stats()`); a budget over a whole turn that
  includes host code (reading, rendering) stays the host's guard.
- **Legends and the interpreter.** It keeps its legend loader and interpreter "until the
  library covers it". The library's `World` is the interpreter; PSys2's legend dialect
  (`core.key`, `core.operation`) is mapped by `compat/psys2/mapping.sop`; a host keeps
  only the mapping, not a second interpreter.
- **The card generator and coverage grid** it lists as "lib when agreed": they are here
  (`schemaCard`, `schemaGrid`) for worlds declared with std.schema; its cards of other
  worlds (rule worlds) stay generated by it until those worlds declare a schema.
