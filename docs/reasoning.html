Reasoning

Five ways to use the same matrix. Each section shows the wires that matter and what the library returned when the example ran.

Deduction

Telling a fact runs the rules. Recursive rules reach a fixpoint; a deny stops impossible conclusions.

Completion

The logical counterpart of predicting the next token: given the current circuit, produce the values that must follow and questions for the rest.

CallReturns
open(id?)Required keys without a value
suggest(id, key)Values the world accepts, that also leave the other open keys completable
next()Forced fills, default fills, core.question wires, dead keys. Changes nothing
complete({ defaults })Commits forced fills one by one, since each can force the next
complete({ choose: true })Also commits one full solution for what is still open, as assumptions
solve()One joint assignment of all open keys with a closed domain, or null. See Solvers

A value is offered only if a full completion still exists with it. A third meeting for 3 people gets the small room directly, because the big room is taken at both times. With strict: true, a statement that leaves no completion at all is refused with dead-end.

Defaults are assumptions. Telling a different value replaces the default and everything that followed from it; the result lists what was dropped in revised.

Abduction

Given something observed, find what would have to be assumed. Candidates are found backwards through the rules, then each one is verified forwards in a scratch transaction, so denies prune explanations.

The assumption can also be the value of an open key of an existing wire, declared with core.abducible of=patient key=condition:

Abduction goes through calculations. With a rule "change = paid − total", a payment whose total is 15 and paid declared abducible, the value is computed, not guessed:

add, sub, mul and div are solved for one missing argument, along a chain of rules if need be. For any other function the values of the slot's enum or range are tried.

Explanations come back minimal and cheapest first. cost= on the abducible sets how reluctant the world is to assume it.

Induction

From example circuits to a rule. What is equal in all examples stays constant; what differs becomes a variable; the same pair of differing values becomes the same variable, which recovers co-reference. Wire order in the examples does not matter.

A value of the conclusion that is computed from the premises (sum, difference, product, ratio) is recognised:

  • Patterns of the same type must match different wires, so "two bookings" never means one booking twice.
  • negatives: circuits the rule must not match. The comparison between variables that excludes them is added (qty <= stock); a negative that nothing separates is reported in coversNegative.
  • kind: 'deny' learns a constraint from examples of forbidden states.
  • tolerant: true skips examples of a different shape and reports them.
  • induceSlots(wires) proposes slots: required keys, reference types, small enums.
  • Telling a learned rule to a world validates it there. A rule whose consequences hit a deny is refused.

Revision and explanation

Retraction is incremental. Rule firings that read a removed wire are undone, their inputs go back on the agenda, and the chase derives again what still has support. A wet lawn explained by rain and by a sprinkler stays wet when the rain is retracted. The test suite checks that the incremental result equals a rebuild from scratch on five worlds.
