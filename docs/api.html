API

Everything exported by the package. Type declarations are in src/index.d.ts.

World

OptionMeaning
fnsFunctions for core.calc and core.check: (args, world) => value
libraryMatrix texts by name, loaded with core.use
maxDepthLongest chain of derivations
lookaheadSuggestions must leave a full completion possible
strictRefuse changes that leave no possible completion
solverSearch strategy for completion; see Solvers
searchBudgetSearch nodes one solve may visit; each solver has its own default

Writing

MethodDoes
tell(input, { dry, strict })Add facts and matrix wires, as text or wire objects
load(input)Like tell, throws when refused
fill(id, key, value, { dry, strict })Give a value to an open key
retract(id)Remove a told wire and what depends on it
replace(id, input)Swap a told wire for new wires in one transaction
apply(assignment)Commit an assignment from solve in one transaction
trial(fn)Run fn(world) and undo everything it did
use(name)Load a matrix from the library
step(input, { defaults, strict })tell then complete
answer(question, value)Fill the key a core.question wire asks for

Violations

KindMeaning
denyA core.deny matched; rule, why, wires
conflictA second value for a single-valued key; have, want
domainValue outside enum, or not a reference to the slot type
cardinalitySeveral values on a key that is not many
unknown-keyKey without a slot on a closed type
dangling-refReference to a wire that does not exist
dead-endStrict mode: no completion possible
duplicate-id, syntax, schemaThe input itself is wrong
depth, budgetA derivation ran away
unknown-wire, unsupportedThe wire cannot be filled or retracted
