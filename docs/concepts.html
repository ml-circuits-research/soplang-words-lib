Concepts

The data model in the order you meet it: a wire, a circuit, the matrix, and what happens when the world is told something.

Wire and circuit

  • Values are atoms (water, 10, 10:00), strings ("free text"), references ($id) or variables (?x, only in the matrix and in queries).
  • A key may repeat. A wire may span lines. # starts a comment.
  • A missing key means unknown, not false. A required key without a value is an open question.
  • Wires linked by $id references form a circuit. Wires with no path between them are independent, so parallelism is the default and sequence comes from references.
  • Facts and matrix wires have separate id spaces: a pattern ?m1 does not clash with a fact @m1.

Slots

  • required: the key is an open question until it has a value.
  • type, enum, or min with max and step give the key a closed domain, which makes it searchable. min and max alone are checked on every value.
  • default is an assumption: weaker than anything told, dropped when it gets in the way.
  • id makes the key part of the wire's identity. Two wires of the type with the same identity values are one entity.
  • ask is the question of the key in natural language.

Rules and denies

  • Variables are local to one rule. Inside a rule, $b means the wire matched by pattern ?b or produced by template @b.
  • Code lives only in named functions. Built in: add sub mul div min max concat and eq neq lt lte gt gte before. Pass your own with new World({ fns }).
  • Numbers may carry a unit: 2kg + 3kg = 5kg, 10N / 2kg = 5N/kg, 6m / 2m = 3. Adding different units is not applicable, so the rule does not fire.
  • not= is negation as failure. It is maintained: when a wire arrives that ends the absence, the conclusion is withdrawn. A matrix where a rule negates something its own consequences can produce is refused.
  • A template value whose variable is unbound is left out, so the new wire has an open key.

What a change does

  1. Ingest. Each wire is classified as matrix or fact. A fact with the identity of an existing wire is merged into it.
  2. Chase. Rules run to a fixpoint, driven by the wires that changed. A template that is already satisfied changes nothing; otherwise an existing wire is completed or a new one is created.
  3. Validate. Slots of every touched wire, dangling references, then every deny.
  4. Commit or roll back. With any violation the world is exactly as before.

Same wire or new wire

When a rule produces a wire of a type that has identity keys, the wire with the same identity is completed, and a different value on a single-valued key is a conflict. Without identity keys, an existing wire that already contains everything the template says satisfies it; otherwise a new wire is created. Its id is a hash of the rule and its bindings, so it is the same every time it is derived.

Provenance

Every derived wire and every filled value records the rule (via) and the wires it came from (from). The engine also records each rule firing with what it read and what it wrote. That record is what makes retraction and revision incremental.

Termination

A derived wire has a depth: one more than the deepest wire it came from. A change that would exceed maxDepth (12 by default) is refused, which stops rules that feed themselves.
